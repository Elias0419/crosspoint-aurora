Aurora

CrossPoint Reader, the Aurora fork — flash it from the browser.

This browser can't talk to serial ports

Web flashing needs Web Serial: use Chrome or Edge on a desktop (Windows, macOS, Linux, ChromeOS). Safari and Firefox don't support it.

LilyGo T5 S3 (4.7" touch)

ESP32-S3. Plug in over USB-C, then click Install. If the port doesn't show up, hold BOOT while pressing RST and try again.

Xteink X4 Pro (touch)

ESP32-S3 build with the touch controller and warm/cold frontlight.

Xteink X4 / X3

ESP32-C3 build (buttons only).

Notes

  1. Installing keeps your books and settings: only the bootloader, partition table and the app are written — the SD card is untouched.
  2. Pick Erase device in the dialog only if you want a clean NVS (Wi-Fi credentials, saved state).
  3. Later updates can be installed from the device itself: Settings → System → Update (the fork's releases).
