LilyGo T5 S3 comes in two variants — pick the right one

The Pro and the Pro Lite are the same board, except the Lite ships without the LoRa/GPS module. Aurora gives the Lite's four unused radio pins to you as solderable keys, which is exactly the wrong thing to do on a board that has a radio wired to them.

Look at the back of the board: a metal-canned module with u.FL antenna sockets next to the battery connector means Pro. Bare pads there mean Pro Lite. If you never bought the version with an antenna, you have the Lite.

Nothing here is destructive if you guess wrong — flash the other one and you are back. But a Pro running the Lite build can see phantom key presses from the radio's pins, and updates from the device itself only ever offer the build matching what you flashed.

LilyGo T5 S3 Pro Lite (4.7" touch)

ESP32-S3, no radio fitted. Four extra keys can be soldered to the spare GPIO10 / GPIO1 / GPIO46 / GPIO47 pads and bound in Settings → Controls → Key actions. Plug in over USB-C, then click Install. If the port doesn't show up, hold BOOT while pressing RST and try again.

LilyGo T5 S3 Pro (4.7" touch, LoRa/GPS)

The same firmware, built to leave the radio's four pins alone: no solderable extra keys, and the module's pins stay parked as the board expects. Everything else — panel, touch, IO48, frontlight — is identical.

Xteink X4 Pro (touch)

ESP32-S3 build with the touch controller and warm/cold frontlight.

Xteink X4 / X3

ESP32-C3 build (buttons only).

Notes

  1. Installing keeps your books and settings: only the bootloader, partition table and the app are written — the SD card is untouched.
  2. Pick Erase device in the dialog only if you want a clean NVS (Wi-Fi credentials, saved state).
  3. Later updates can be installed from the device itself: Settings → System → Update (the fork's releases). Each build is tagged with the board it was made for, so a device only ever offers itself the matching one.
